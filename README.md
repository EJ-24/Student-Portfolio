# Student Portfolio Website | CCS114 Midterm Examination

A responsive, multi-section personal portfolio website built as a requirement for the **CCS114 – Web Technologies** Midterm Laboratory Examination at the University of Cabuyao (Pamantasan ng Cabuyao). 

This project demonstrates the practical application of HTML5, CSS3, and the Bootstrap 5 framework to create a modern, visually consistent, and mobile-friendly web experience.

## 🚀 Features

The portfolio is structured into a single-page layout featuring the following sections:

*   **Navigation:** A responsive Bootstrap fixed-top navbar for seamless scrolling.
*   **Homepage:** A hero section introducing the student, their course, and a personal motto.
*   **About Me:** A professional background summary alongside a visual representation of technical skills using Bootstrap progress bars.
*   **Gallery:** A responsive grid layout utilizing Bootstrap Cards to display six (6) personal and academic portfolio images with hover overlay effects.
*   **Mission & Vision:** A dedicated section highlighting the University of Cabuyao's Mission and Vision using side-by-side cards, paired with an interactive Bootstrap Accordion detailing the institution's Core Objectives.
*   **Contact Me:** A functional form layout complete with a stylized Bootstrap Alert banner and an interactive Modal pop-up to confirm message submission.

## 💻 Technologies Used

*   **HTML5:** Semantic structuring of web content.
*   **CSS3:** Custom styling, hover effects, and theme integration (inspired by the Kards template).
*   **Bootstrap 5.3.2:** Core framework utilized for the grid system and 10+ UI components (Navbar, Cards, Modals, Accordions, Progress Bars, Buttons, Badges, Alerts, Forms).
*   **FontAwesome 6.4.0:** Scalable vector icons used throughout the layout.
*   **Google Fonts:** Utilizing the 'Poppins' typeface for clean, modern typography.
